# RAILab × Physical Intelligence

Single-page site for RAILab's Physical Intelligence API beta application. See `SPEC.md` for content and design decisions.

Plain HTML + CSS, no build step. Open `index.html` in a browser to preview.

## Deploy to GitHub Pages

1. Push this folder to a GitHub repo.
2. Settings → Pages → Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
